# Scene Sketch Spec：草图与细节

[English](README.md)

一个轻量的生图工作流 skill：先用代码画构图草图，同时把创意和细节持续保存到文件，再在用户要求成图时调用 ImageGen。

## 流程

1. 在 `spec.md` 中区分已确认要求、暂定想法和本轮修改，方便从文件恢复上下文。
2. 使用 SVG、Canvas、简单三维等可用工具制作并修改草图，保留可编辑源文件。
3. 展示带批注的草图供讨论，并从同一构图导出干净参考图。
4. 用户要求最终图片或授权完整试验后，向 ImageGen 提交干净草图和必要细节，保存实际提示词及全部成图，并核对结果。

只要求草图时做到草图。用户会话记录、素材和生成结果应保存在本仓库之外。

## 提示词自由

这个 skill 不规定提示词使用什么语言、分几段、采用什么句式、写多长，也不提供固定模板或自动追加画风、镜头及质量词。具体写法由当前模型结合用户意图和工具要求决定。

## 文件

`SKILL.md` 是可复用的技能说明。本仓库不捆绑绘图程序，具体绘图和渲染工具由助手选择；最终生图需要能调用 ImageGen。

当前为实验版本，草图与成图都需要对照已确认要求进行审阅。
