# Scene Sketch Spec：草图与细节

[English](README.md)

一个按需启用的轻量 skill：当你已经有构图想法时，先把构图画成可修改的草图，再把草图和保存的细节交给 ImageGen 生成具体图片。

## 什么时候使用

- 你明确要求先画构图草图、用草图讨论画面，或修改已有构图草图。
- 你已经有具体构图灵感，希望先将画面安排画出来、对齐或修改，再生成最终图片。

用日常语言表达即可，例如：“从门外往房间里看，近处门框遮住一部分，人物站在房间深处。”不需要先懂焦段、算透视，也不用自己动手画草图。

## 什么时候不触发

- 你只有情绪、氛围、题材或意境，希望模型自由构思画面。
- 你只说“我有个灵感”，没有表达构图，也没有要求先画草图。
- 你要求“直接成图”“跳过草图”或“让模型自己决定构图”。
- 你只是在讨论这个技能或生图方法。

不确定时默认不启用，按当前请求继续。不要求用户为了进入流程而先想清构图或回答专业问题。已有草图文件或 `spec.md` 也不会自动触发；后续要求跳过草图时，以最新请求为准。

## 为什么先画草图

已有构图想法时，草图可以让主体位置、比例、透视和前后遮挡变得可见，先检查和修改，再生成最终图片。这套流程来自作者使用参考图生图的体验，并非经过基准测试、适用于所有生图模型的效果保证。成图是否偏离构图，仍需实际看图核对。

没有构图想法时，直接让模型生成、探索画面即可。这个技能不是所有生图请求都必须经过的前置步骤。

## 流程

1. 满足启用条件后，在 `spec.md` 中区分已确认要求、暂定想法和本轮修改，方便从文件恢复上下文。
2. 使用 SVG、Canvas、简单三维等可用工具制作并修改草图，保留可编辑源文件。只画解释构图所需的线条，不擅自补齐五官、服装等外观约束。
3. 展示带批注的草图供讨论，并从同一构图导出干净参考图。
4. 用户要求最终图片或授权完整试验后，向 ImageGen 提交干净草图和必要细节，保存实际提示词及全部成图，并核对结果。

只要求草图时做到草图。构图变化时再改草图；仅外观细节变化时，可以只更新细节记录和生图提示。用户会话记录、素材和生成结果应保存在本仓库之外。

## 提示词自由

这个 skill 不规定提示词使用什么语言、分几段、采用什么句式、写多长，也不提供固定模板或自动追加画风、镜头及质量词。具体写法由当前模型结合用户意图和工具要求决定。

## 文件

`SKILL.md` 是可复用的技能说明。本仓库不捆绑绘图程序，具体绘图和渲染工具由助手选择；最终生图需要能调用 ImageGen。

当前为实验版本，草图与成图都需要对照已确认要求进行审阅。
